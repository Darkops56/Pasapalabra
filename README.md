## 🚀 Guía de Instalación Rápida

El proyecto está diseñado para ser clonado y levantado en cualquier máquina (Windows, Mac, Linux)

### 1. Clonar el repositorio

Para clonar el repositorio debemos ejecutar lo siguiente en la terminal:
```bash
git clone https://github.com/Darkops56/Pasapalabra.git
cd Pasapalabra
```

### 2. Instalar las dependencias
```bash
npm install
```

### 3. Levantar el proyecto

```bash
npm run dev
```

Luego, apretar CTRL + Click Izquierdo en el enlace que te da la terminal para abrir la pagina en la que escucha el proyecto.
